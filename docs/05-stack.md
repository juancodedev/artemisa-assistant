# Stack Tecnológico

| Pieza | Herramienta | Costo para empezar | Alternativa |
|---|---|---|---|
| Canal de conversación | WhatsApp Business API (Cloud API de Meta) | $0 — pago por mensaje en producción (ojo con el cambio de precios del 1 oct 2026) | BSP como Wati o 360dialog (agregan mensualidad propia) |
| Motor de IA | Claude API (modelo Haiku 4.5) | $0 de licencia, pago por uso (tokens) | Otro proveedor de LLM (ej. OpenAI) |
| Base de datos + Login (Google) + Backend | Supabase | $0 con plan gratuito | Firebase |
| Hosting del dashboard | Cloudflare Pages | $0 (permite uso comercial en el plan gratuito) | Vercel (ojo: su plan gratuito/Hobby restringe uso comercial) |

**Costo inicial total: $0.** Los costos variables aparecen con uso real (mensajes de WhatsApp + tokens de Claude), y son bajos a poco volumen.

⚠️ Los límites de planes gratuitos y precios cambian seguido — confírmalos en el sitio oficial de cada herramienta antes de decidir.
