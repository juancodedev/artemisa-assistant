# Roadmap

## Fase 1 — Probar que el bot conversa bien (PRÓXIMA FASE)
Un psicólogo de prueba, con sus datos cargados directamente en la base de datos (sin dashboard ni login todavía). El bot ya funciona en un WhatsApp real: responde preguntas y entrega el link de Cal.com cuando corresponde.
**Termina con:** una conversación real de WhatsApp que se puede mostrar, donde el bot responde bien.

## Fase 2 — El psicólogo se independiza
Se construye el dashboard completo: login con Google, formulario de configuración (F1 + F2). Ya no se toca la base de datos a mano — cualquier psicólogo entra solo y carga sus propios datos.
**Termina con:** un psicólogo real se registra y configura todo sin ayuda externa.

## Fase 3 — Piloto con varios psicólogos reales
2-3 psicólogos usándolo con pacientes de verdad durante un tiempo.
**Termina con:** datos reales — cuántas conversaciones terminaron en un link de Cal.com entregado, y feedback directo de los psicólogos.
